# Sorting method
In Python, sorting methods refer to the algorithms used to arrange elements in a list or other data structure in a specific order, such as ascending or descending. Python provides several built-in sorting methods, including:

1. sort(): Sorts the elements of a list in place.
2. sorted(): Returns a new sorted list from the elements of any sequence.

Selection Sort is a simple comparison-based sorting algorithm that works by repeatedly finding the minimum element from the unsorted part of the list and swapping it with the first element of the unsorted part.

1. Divide the list into two parts: the sorted part (initially empty) and the unsorted part (the entire list).
